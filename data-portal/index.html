Why scientists can trust it

The field's number one weakness is data provenance. Multi-lab studies keep training models on noise. We built the layer that fixes that.

Medallion lineage

Raw instrument and literature data lands in bronze. Cleaning and provenance attachment happens in silver. Only benchmark-ready, fully-attributed records reach gold. Nothing floats without a source.

Method codes on every row

Every measurement carries its analytical method as a first-class field. Records with missing or unknown methods quarantine automatically: they are never silently mixed into your analysis.

Blind benchmarks

Each dataset ships with a sealed, falsifiable benchmark. Predict first, measure later, score against lab-grade truth. Leaderboards are versioned and citable.

Versioned and citable

Every release gets a version and a DOI. Cite the exact data your paper ran on, and anyone can reproduce it: the version never changes under you.

Pricing, stated plainly

Everything sits behind the paywall. A Twistor subscription is required, and on top of that you pay for what you use.

API quickstart

Reads need your org ID and an active subscription. Mutations need an API key. Base URL is configured per deployment.

List dataset versions 
curl -H "X-Org-Id: your-org-id" \
  https://api.twistor.example/data/v1/science/carbon/datasets
Query with method comparability 
curl -H "X-Org-Id: your-org-id" \
  "https://api.twistor.example/data/v1/science/carbon/query?carbon_pool=soil-organic&comparable_group=dry-combustion"
Download the Excel version 
curl -H "X-Org-Id: your-org-id" \
  https://api.twistor.example/data/v1/science/carbon/datasets/v1.0/download \
  --output carbon-trust-v1.xlsx

Full endpoint reference ships with each dataset page. The base URL above is a placeholder until the production API deploys.

Questions researchers ask

Is the data real?

V1 seeds are synthetic and labeled as such on every row: we say so upfront. Real-data ingestion is underway, and versions will always tell you exactly what you are looking at.

How do I cite a dataset?

Every release carries a version and a DOI. Cite the version your work ran on; it is immutable and reproducible.

What does the subscription cost?

Subscription tiers are set at provisioning based on your lab's expected volume. API tolls and Excel fees are always stated before you incur them: no surprise billing.

Can my whole lab share one subscription?

Yes. Subscriptions are per organization; API keys are issued per key with lane scopes and rate limits.

Do you take data contributions?

Yes: signed lab ingestion with calibration chains is how the gold tier grows. Talk to us about becoming a contributing lab.
